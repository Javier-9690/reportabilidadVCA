Importar curva y reportabilidad

El sistema cruza la curva de poblamiento contra la dotación enviada por empresa y genera el Excel final normalizado.

Procesar archivos

Hoja esperada: Fcst_Autorizado VCA. ID base: ID de la solicitud.
Permite una o varias empresas. ID esperado: N° DE ID.

Control de reportabilidad

Identifica las empresas que tienen dotación planificada en la curva, pero que no aparecen dentro de los archivos cargados como reportabilidad.

Exportación Excel

El archivo final mantiene el formato requerido con ID, módulo, RUT, nombre completo, empresa, contrato, gerencia, turno, CO MEL, género y nombre de turno.
